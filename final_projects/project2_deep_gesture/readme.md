# Hand Posture Classification

This project trains a ResNet18 transfer-learning classifier for 6 hand posture
classes:

```text
A, B, C, Five, Point, V
```

The current model pipeline keeps the model architecture stable and focuses on
reproducible data splitting, deterministic validation/test preprocessing, and
submission-friendly prediction output.

## Project Structure

```text
.
├── data/
│   ├── raw/                 # Original labeled images, one folder per class
│   ├── train/               # Stratified training split
│   └── val/                 # Stratified validation split
├── models/
│   └── resnet_model.py      # ResNet18 builder
├── outputs/                 # Prediction files and generated visual reports
├── test_images/             # Images to classify for submission/testing
├── split_dataset.py         # Stratified train/val split helper
├── train.py                 # Training entry point
├── test.py                  # Batch prediction entry point
├── evaluate.py              # Prediction result analysis helper
├── visualize_dataset.py     # Dataset distribution/sample visualization helper
└── requirements.txt
```

## Environment

Create or activate a Python environment with PyTorch and torchvision. On this
machine, the Anaconda `base` environment has CUDA support:

```powershell
conda activate base
python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0))"
```

Install dependencies:

```powershell
pip install -r requirements.txt
```

If `torch.cuda.is_available()` prints `False`, the active Python environment is
probably using a CPU-only PyTorch build. Activate the CUDA-capable environment
before training.

## Prepare Data

The expected raw dataset layout is:

```text
data/raw/
├── A/
├── B/
├── C/
├── Five/
├── Point/
└── V/
```

Create a reproducible stratified 80/20 split:

```powershell
python split_dataset.py --raw_dir data/raw --train_dir data/train --val_dir data/val --val_ratio 0.2 --seed 42
```

If `data/train` or `data/val` already contains files and you want to recreate
the split:

```powershell
python split_dataset.py --overwrite
```

## Train

```powershell
python train.py
```

The best checkpoint is saved to:

```text
checkpoints/best_model.pth
```

The checkpoint stores:

```text
model_state_dict
class_to_idx
classes
best_acc
```

`test.py` reads the class mapping from the checkpoint, so prediction labels stay
aligned with the exact training class order.

During training, `train.py` also records epoch-level history and updates the
training curve visualization after each epoch:

```text
outputs/training_history.csv
outputs/training_curves.png
```

The CSV contains:

```text
epoch, train_loss, train_acc, val_loss, val_acc, learning_rate, is_best
```

These files are generated by future training runs. Adding the logging code does
not recreate curves for an old training run unless its epoch logs are available.

## Predict

Put PNG images into `test_images/`, then run:

```powershell
python test.py --image_dir ./test_images --model_path ./checkpoints/best_model.pth
```

By default, predictions are written to:

```text
outputs/result.txt
```

Output format:

```text
filename label
```

Example:

```text
test_A1.png A
test_C1.png C
test_Sign 5 (1).png Five
```

## Visualize Dataset

Generate class-count charts and class sample grids:

```powershell
python visualize_dataset.py --raw_dir data/raw --train_dir data/train --val_dir data/val --output_dir outputs/visualizations
```

Generated files include:

```text
outputs/visualizations/class_distribution.png
outputs/visualizations/raw_samples.png
outputs/visualizations/train_samples.png
outputs/visualizations/val_samples.png
outputs/visualizations/class_counts.csv
```

## Visualize Training History

After a training run has generated `outputs/training_history.csv`, redraw the
training curves without retraining:

```powershell
python visualize_training_history.py --history outputs/training_history.csv --output_dir outputs/training_visualizations
```

Generated files include:

```text
outputs/training_visualizations/training_curves_combined.png
outputs/training_visualizations/training_loss_curve.png
outputs/training_visualizations/training_accuracy_curve.png
outputs/training_visualizations/learning_rate_curve.png
```

## Analyze Prediction Results

If the test image filenames contain label hints such as `test_A...`,
`test_C...`, `test_V...`, or `test_Sign 5...`, analyze `outputs/result.txt`:

```powershell
python evaluate.py --predictions outputs/result.txt --output_dir outputs/evaluation
```

Generated files include:

```text
outputs/evaluation/summary.txt
outputs/evaluation/confusion_matrix.png
outputs/evaluation/confusion_matrix.csv
```

This helper is only for local diagnosis. It does not change the model or the
checkpoint.
